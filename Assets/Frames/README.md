# Frames

Flat iPhone mockups from [Pomme Plate](https://github.com/ephread/PommePlate) by ephread, released under **CC0 1.0 Universal**, so no attribution or restrictions. Their screens are a solid colour; Capstand cuts the screen out when you import one.

Every PNG in this folder is shipped inside the app and gets its own item in the **Frame** menu. To add one, drop the PNG in here and rebuild. More models and colours are in the Pomme Plate repo under `iPhone/PNG/`. The X/XS/11 Pro shape is closest to a current iPhone's screen proportions.
